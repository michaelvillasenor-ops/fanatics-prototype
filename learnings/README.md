# learnings/

Dated reflections written by the loop skills at the end of each run. `/skill-refine` clusters
them into PRs against the pack.

- Filename: `YYYY-MM-DD-<skill>-<kebab-slug>.md`
- Frontmatter: `skill`, `date`, `surface` (+ `lens` for feedback, `reviews` and `verdict` for ship)
- Sections: What worked · What was missing · What felt forced · Proposed addition
- Processed files get `> Synthesized into <PR> on <date>.` appended.

**This folder is checked in. Keep confidential or sensitive details out.**
